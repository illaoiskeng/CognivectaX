CognivectaX is a systematic, Sharpe-optimized technology equity strategy.

The strategy constructs a diversified portfolio of 40–70 global tech and semiconductor stocks, 
optimizing weights for maximum risk-adjusted return using rolling covariance estimation.

Features:
- Sharpe-optimized portfolio construction
- Monthly/Quarterly rebalancing
- Stress-tested cost assumptions
- Interactive dashboard with portfolio analytics

Built with Python + Streamlit.
